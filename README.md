# MartletPoison

Turtle WoW（1.18.1）盗贼涂毒助手。全新独立插件，**不改动 EzPoison 任何文件**。

## 开发与部署

本仓库是源代码真身，游戏目录下的 `Interface\AddOns\MartletPoison` 只是部署产物。

- 改代码 → 在仓库里改
- 部署 → 双击 `deploy.bat`（或把仓库内文件手动复制到游戏目录），游戏内小退重登生效
- 客户端兼容注意：这是 Lua 5.0 系的老客户端，且改版客户端有两个坑——全局 `MP` 被预置占用、for 循环控制变量在闭包里读到 nil（见 `MartletPoison.lua` 里 createIcon 工厂函数的注释）

## 核心原则

所见即所涂：没有方案、没有下拉菜单、没有任何**影响行为**的隐藏状态。
屏幕上的图标 = 毒药/磨刀石种类本身，点击 = 操作。
（唯一的记忆：每只手最后一次涂的种类，仅用于角标显示，不驱动任何点击行为。）

## 主面板

- 仅横排一行（竖排切换暂不做）
- 种类固定、顺序固定（按使用频率）：

  速效 → 致命 → 致伤 → 致残 → 麻痹 → 腐蚀 → 溶解 → 煽动 ｜ 致密磨刀石 → 神圣磨刀石 → 元素磨刀石 → 致密平衡石

- 按职业过滤（盗贼 = 8 毒 + 4 石；其他职业显示对应的石/油，顺序同样固定）
- 行末一个**常驻小 ▸ 按钮** = 抽屉开关；展开后在主行下方多出一行，显示被隐藏的种类（去色置灰）
- 中键点主行图标 = 收进抽屉；中键点抽屉图标 = 放回主行
- 隐藏清单、抽屉开合状态随角色存档

## 鼠标操作

- 左键 = 涂主手
- 右键 = 涂副手
- 中键 = 藏 / 放该种类
- 永远使用背包中该种类**最高等级**的一瓶；想涂低级的自己开背包

## 角标系统

- **左上** = 主手剩余：次数型显示剩余次数，时间型显示剩余时间
- **右上** = 副手剩余：同上
- **右下** = 背包总库存，白色常显
- 角标颜色按剩余比例：>50% 绿 → >25% 黄 → <25% 橙 → 0 红（系统标准色 + 描边字）
- 毒药平时显示次数；时间剩余 <5 分钟时角标切换为剩余时间并标红（阈值可调）
- **角标跟随"该手最后一次涂的种类"**：附魔还在显示实时余量；附魔没了（用尽/超时/换武器）显示红色 **0**
- 红色 0 的含义："这只手空着，上次涂的是这个"，看到即可无脑点同一图标补涂；换涂别的种类后角标自然跟到新图标
- 该记忆随角色存档，仅用于显示

## 悬停 Tooltip

种类名 ｜ 背包内各等级数量（如"速效毒药 VI ×3"）｜ 主/副手当前附魔余量 ｜ 灰字操作提示

## 技术要点

- 涂抹复用 EzPoison 已验证的连招（使用毒药 → 点武器槽 → 确认替换），左右键同一套原子操作
- 数据表：物品 ID + 各等级名称（静态）；满次数/满时长在涂抹时自动标定并随角色存档（角标百分比颜色的基准）
- 时间类角标需要 1s OnUpdate 主动刷新
- 适配 pfUI 皮肤
- 保留：位置拖动/锁定、缩放；原"未激活褪色"选项取消（被角标取代）

## 明确不做

- 方案（配置文件）概念
- 竖排布局
- 图标拖拽排序
- 等级选择（永远最高级）
- Auto-Apply 补涂键
- 面板显示/隐藏之外的按键绑定

## 与 EzPoison 的关系

两个插件独立共存、互不影响；本插件定稿后建议停用 EzPoison，避免两层面板。
v0.1.0 只做涂毒面板；制毒购买助手（buyer）暂仍由 EzPoison 提供，面板定稿后整体迁入。
